# GC-SSM

GC-SSM (Graph-Conditioned Selective State Space Model) is a multivariate time-series anomaly detector that conditions selective state-space parameters on dynamically learned cross-sensor structure.

## Installation

- Create a virtual environment from the repository root:

  ```bash
  python3.11 -m venv .venv
  source .venv/bin/activate
  python -m pip install --upgrade pip setuptools wheel
  ```

- Install a CUDA-enabled PyTorch build first by following the command generated by the [official PyTorch selector](https://pytorch.org/get-started/locally/). Then install every remaining project dependency from `requirements.txt`:

  ```bash
  python -m pip install packaging ninja
  MAMBA_KEEP_CUDA_BUILD=TRUE python -m pip install -r requirements.txt --no-build-isolation
  ```

  - `MAMBA_KEEP_CUDA_BUILD=TRUE` enables the Mamba selective-scan CUDA extension. `--no-build-isolation` ensures that the build uses the CUDA-enabled PyTorch installation from the active environment.

## Dataset setup

- Download TSB-AD-M from the [official dataset URL](https://www.thedatum.org/datasets/TSB-AD-M.zip) and download [`TSB-AD-M-Eva.csv`](https://github.com/TheDatumOrg/TSB-AD/blob/main/Datasets/File_List/TSB-AD-M-Eva.csv) from the official TSB-AD repository.
- Place them in the following relative paths:

  ```text
  data/TSB-AD-M/*.csv
  data/File_List/TSB-AD-M-Eva.csv
  ```

## Running

- From the repository root, run GC-SSM on all 180 files in the official TSB-AD-M evaluation list:

  ```bash
  python -m gc_ssm
  ```

- CLI arguments override the Python dataclass defaults. For example:

  ```bash
  python -m gc_ssm \
    --d-model 64 --d-state 32 --num-blocks 4 \
    --lr 0.001 --epochs 50 \
    --batch-size 64 --model-window 64
  ```

- Run `python -m gc_ssm --help` for all customizable CLI arguments.

## Notes

- GPU-accelerated GC-SSM requires Linux, an NVIDIA GPU, CUDA 11.6 or newer, and Python 3.11.
- `causal-conv1d` and `mamba-ssm` are required for normal GPU execution. GC-SSM retains a pure PyTorch selective-scan fallback for environments where the Mamba CUDA kernel cannot be imported, but fallback execution is substantially slower.
- Verify that CUDA, `causal-conv1d`, and the Mamba selective-scan kernel are all available to GC-SSM:

  ```bash
  python - <<'PY'
  import torch
  import causal_conv1d
  from gc_ssm.models.block import mamba_available

  assert torch.cuda.is_available(), "CUDA is not available to PyTorch"
  assert mamba_available(), "Cannot load the Mamba selective-scan kernel"
  print("CUDA selective scan is available")
  PY
  ```
